# Ferrari vs S&P 500 — Return & Regression Analysis

Compares Ferrari (RACE) and S&P 500 performance from 2020–2026.

## What's inside
- Total and annualized returns
- Cumulative return comparison (Plotly)
- Correlation and daily excess returns
- Linear regression: Beta (0.92), Alpha, R² (0.40)

## Libraries
`yfinance`, `pandas`, `matplotlib`, `plotly`, `scipy`

## How to run
1. `pip install yfinance pandas matplotlib plotly scipy`
2. Open `Ferrari-v-S_P500_.ipynb` in Jupyter and run all cells
